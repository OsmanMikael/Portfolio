# My Portfolio - Osman Mikael

Dette er en personlig porteføljeapplikasjon bygget med React og TypeScript.

## Tilgjengelige Scripts

I prosjektkatalogen kan du kjøre:

### `npm start`

Kjører appen i utviklingsmodus.\
Åpne [http://localhost:3000](http://localhost:3000) for å se den i nettleseren.

### `npm test`

Kjører testene.

### `npm run build`

Bygger appen for produksjon i `build`-mappen.

## Teknologier brukt

- React 18
- TypeScript
- Bootstrap 5
- Font Awesome
- Scroll Reveal
